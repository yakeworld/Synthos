# Golden 集合 · ellipse-3d-anatomy-constrained

> Golden 集合是测试的单一真理来源。所有改进必须通过 golden 测试。
> 对应 SKILL.md「Golden 集合 · GOLDEN SET」小节（ELLI-001…ELLI-006）。

## 语义

本技能将二维椭圆参数反推为三维空间圆几何参数，通过解剖约束
**R_eyeball = 2·R_iris、d = √3·R_iris** 消除方位角模糊（自由度 2→0）。
输出：3D 法向量 n=[sinα·sinβ, -sinα·cosβ, cosα]（cosα=b/a）、虹膜中心 3D
（z1 实数）、由 ≥2 帧光轴投影直线交点迭代收敛得到的眼球中心、Rodrigues
旋转矩阵 M = I + [v]_x + [v]_x²/(1 + O·O')。Golden 集合覆盖：

- **正常路径**：两帧椭圆（均 a≥b）+ 已知 R_iris，Center_eye 在 XY 平面 (z=0) →
  完整求解。
- **错误路径**：单帧输入 → 方位角模糊无法消除，拒绝求解眼球中心（不编造），
  返回带上下文与恢复指引的错误。

## 通过标准

1. 每个 case 的 `expected_status` 与实际执行状态一致（success/error）。
2. 正常 case（容差：浮点 1e-4）：
   - cosα₁=b/a=0.625、cosα₂=0.5625，均 ∈ [-1,1]（验证清单第1条）；
   - ‖n‖=1 且 n 与公式一致（验证清单第2条）；
   - 解剖约束代入：R_eyeball=10.0，自由度 2→0（验证清单第3条）；
   - z1=4.658794 为实数，虹膜中心 3D=[1, 2, z1]（验证清单第4条）；
   - 眼球中心=(3.614905, -6.453278, 0) 为两帧光轴投影直线
     cosβ·(x-px)+sinβ·(y-py)=0 的交点（验证清单第5条）；
   - 迭代收敛：残差 < 1e-6，且与初始估计无关（验证清单第6条）；
   - Rodrigues M 满足 Mᵀ·M=I、det=+1（验证清单第7条）。
3. 错误 case：`eye_center_computed=false`；不输出虚数/编造中心（准确优先）；
   `error.message_must_include` 两条均出现（上下文、恢复指引）；
   可计算部分（单帧 n）可如实输出但中心必须拒绝。
4. 原则优先级：准确 > 证据 > 可复现 —— 所有数值可由输入独立重算复现
   （P1）；z1 为虚数（3R_iris²-(Δx)²-(Δy)²<0）时同样按 ELI-003 报错而非输出虚数。
5. 验证失败时必须记录原因与修复措施。
