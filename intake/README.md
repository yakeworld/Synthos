# intake/ — 外部营养采集内化存档

**用途**: 每日外部营养采集（cron）将评分 ≥8/10 的外部资源（工具/论文/框架）落盘为内化建议，供进化引擎（.evolution/）与后续会话消费执行。

**约定**:
- 文件名: `YYYY-MM-DD-external-nutrition.md`
- 每条高价值资源包含: 名称/类型/地址/数据/用途/内化理由/建议操作/状态
- 7-7.9/10 资源入"观察列表"，不落建议
- 内化执行后更新"状态"字段（待执行 → 已执行 + 证据）

**消费方**:
- 进化引擎评估循环（.evolution/）可将未执行的建议作为优化方向候选
- 后续会话搜索 `intake/` 获取未执行建议，执行后回写状态

**纪律**: 所有数值必须可溯源（stars/日期/评分来自采集当日快照），不伪造。
